# Legiit Overviews

Tracks a Google AI Overview every day, finds what keeps showing up, reverse-engineers the pages it cites, and writes a brief for a page that can get cited. Built on DataForSEO, the Claude API and Supabase.

| File | What it is |
|---|---|
| `PLAN.md` | The build plan: stack, APIs, schema, functions, build steps |
| `CLAUDE.md` | Instructions for Claude Code sessions |
| `docs/progress.md` | Build checklist |
| `docs/source-thread.md` | The X thread the product automates |
| `docs/research/` | Background research (vendors, competitors, AI Overview studies); reference only |

To start: open a Claude Code session here and say "do step 1".
