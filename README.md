# Legiit Overviews

Captures a Google AI Overview every 3 hours, counts exactly what keeps showing up with evidence for every number, reverse-engineers the pages it cites, writes a brief for a page that can get cited, and tracks whether yours does. Built on DataForSEO, the Claude API and Supabase.

| File | What it is |
|---|---|
| `PLAN.md` | The build plan: capture, pattern analysis, page analysis, brief, tracking, schema, functions, build steps, costs |
| `CLAUDE.md` | Instructions for Claude Code sessions |
| `docs/progress.md` | Build checklist |
| `docs/source-thread.md` | The X thread the product automates |
| `docs/research/` | Background research (vendors, competitors, AI Overview studies); reference only |

To start: open a Claude Code session here and say "do step 1".
